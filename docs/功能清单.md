
# 基于Hadoop的考研参考资料推荐系统

## 功能清单

### 1. 用户模块
- 注册 / 登录 / 找回密码  
- 个人信息管理（目标院校、专业、备考阶段）  
- 收藏、评分、浏览历史管理  
- 个性化推荐偏好设置  

### 2. 推荐模块
- 基于协同过滤的个性化资料推荐  
- 基于内容分析的相似资料推荐  
- 推荐列表展示与刷新  
- 用户反馈优化推荐结果（点赞/踩）  

### 3. 资料模块
- 资料列表浏览与关键词搜索  
- 资料详情查看（分类、简介、评分）  
- 资料增删查改（管理员权限）  
- 资料分类标签管理  

### 4. 数据分析与挖掘模块
- 用户行为日志清洗与去重  
- 用户画像分析（备考阶段、院校热度）  
- 资料热度与点击趋势可视化  
- 协同过滤模型训练与更新  

### 5. AI大模型模块
- 考研智能问答  
- 资料内容摘要生成  
- 个性化学习建议输出  
- 智能语义搜索匹配  

### 6. 管理员模块
- 用户信息增删查改与权限管理  
- 资料批量导入、审核、下架  
- 数据备份与日志查看  

---

## 技术栈

### 后端
- Spring Boot（轻量化Java框架，统一接口）  
- Spring Security + JWT（认证与权限管理）  

### 前端
- Vue.js + ElementUI（响应式界面）  
- HTML / CSS / JavaScript  

### 数据库
- MySQL（用户、资料及行为数据存储）  

### 分布式存储与计算
- Hadoop HDFS（海量数据分布式存储）  
- MapReduce / Spark（批量处理与模型训练加速）  

### 推荐算法
- Python / Java 实现 UserCF / ItemCF 协同过滤  
- TF-IDF 文本特征分析  

### AI模块
- 调用大模型API（DeepSeek / 通义千问）实现智能问答、摘要与学习建议  
- 语义向量检索增强智能搜索  

### 数据分析与可视化
- Python / Pandas（数据处理）  
- ECharts / Chart.js（用户画像与趋势展示）  

### 系统测试与运维
- JUnit / Postman（单元与接口测试）  
- MySQL备份工具（数据备份）  
- Spring Boot日志管理
