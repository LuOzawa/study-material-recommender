## 6. 新电脑从 0 到 1 运行步骤（Windows）

### 6.1 前置安装
1. JDK 17（配置 `JAVA_HOME`）
2. MySQL 8.x
3. Python 3.10+
4. Node.js 18+

### 6.2 导入数据库
在发布包根目录执行：

```bash
mysql -uroot -p < sql/init.sql
```

### 6.3 安装推荐脚本依赖

```bash
cd recommendation
pip install -r requirements.txt
```

### 6.4 启动后端

```bash
cd scripts
start-backend.bat
```

默认后端地址：`http://localhost:8080`

### 6.5 启动前端

```bash
cd scripts
start-frontend.bat
```

默认前端地址：`http://localhost:5173`

## 8. 常见问题排查
- 后端连不上数据库：检查 MySQL 服务、账号密码、3306 端口。
- 推荐接口异常：检查 Python 依赖是否已安装、脚本路径是否正确。
- 前端请求失败：确认后端已运行且 `http://localhost:8080` 可访问。
